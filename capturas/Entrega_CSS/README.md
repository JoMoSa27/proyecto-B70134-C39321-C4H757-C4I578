# Evidencias de la entrega de CSS

| Carpeta | Qué contiene | Herramienta |
|---|---|---|
| `w3c/` | Resultado de validar cada hoja de estilos (una captura por archivo CSS) | Validador de CSS del W3C |
| `contraste/` | Pares de colores de la paleta con su relación de contraste y resultado AA | WebAIM Contrast Checker |
| `stylelint/` | Salida de `npm run lint:css`, sin errores | stylelint con stylelint-config-standard |
